# Swipee Support

Swipeeのサポート、プライバシーポリシー、利用規約を掲載するGitHub Pagesサイトです。

## 公開URL

- `https://swipeelabs.github.io/`
- `https://swipeelabs.github.io/privacy/`
- `https://swipeelabs.github.io/terms/`

`swipeelabs` Organizationの `swipeelabs.github.io` リポジトリへpushすると、GitHub Actionsが静的サイトを生成して公開します。

公開前に、トップページと各ポリシーページの問い合わせ先を実在するメールアドレスへ変更してください。
